# DEVICE CHECKUP POC

한국어 브라우저 기반 PC·휴대폰 기본 상태 점검 허브.

공개 URL: https://gsh4124-cyber.github.io/pc-checkup/

## PC 점검
- 키보드 입력 / 동시입력
- 마우스 버튼 / 휠 / 빠른 연속클릭 보조 감지
- 마이크 레벨 / 파형
- 웹캠 미리보기 / 입력 해상도
- 스피커·헤드폰 L/R 테스트
- 모니터 단색 전체화면
- 5분 전체 점검 체크리스트(LocalStorage)

## 휴대폰 점검
- 터치 / 멀티터치
- 화면 색상 / 불량화소 육안 점검
- 전면 / 후면 카메라
- 마이크 입력 레벨
- 스피커 테스트 톤
- 진동 API 지원 여부 / 진동 테스트
- 화면 방향 감지

## 검사 한계
브라우저에서 접근 가능한 기능만 확인합니다. SSD·RAM 심층 상태, 배터리 실제 열화, 침수·수리 이력, 저장장치 건강, 통신·안테나 품질처럼 브라우저만으로 신뢰성 있게 판정할 수 없는 항목은 정상이라고 보증하지 않습니다.

카메라·마이크 입력은 브라우저 검사에 사용하며 서버로 전송하는 애플리케이션 코드가 없습니다.

## 로컬 실행
정적 파일이므로 로컬 서버 사용을 권장합니다.

```bash
python -m http.server 8080
```

브라우저에서 `http://localhost:8080` 접속. 카메라/마이크는 브라우저 보안 정책상 HTTPS 또는 localhost에서 권한이 정상 동작합니다.

## 상태
POC / PUBLIC DEPLOYED / PC·MOBILE REAL-DEVICE QA PENDING.

구현·배포 완료를 실제 장비 정상 검증이나 시장 성공으로 취급하지 않습니다.
