새 휴대폰 · 중고 거래 전

휴대폰 5분 점검

각 항목에서 아래의 통과 기준만 확인하면 됩니다.

1. 터치·멀티터치

아래 영역을 한 번 천천히 훑고, 두 손가락도 동시에 올려보세요.

통과 기준손가락을 움직인 모든 위치에서 반응하고, 두 손가락 입력이 동시에 잡히면 정상.
화면을 손가락으로 훑어보세요
현재 동시 터치 0 · 최대 0

2. 화면 색상·불량화소

색상을 바꾸며 화면 전체를 눈으로 확인하세요.

통과 기준밝은 점·검은 점·특정 색으로 고정된 점·큰 얼룩 없이 화면이 고르게 보이면 정상.

3. 전면·후면 카메라

전면과 후면을 각각 한 번 켜보세요.

통과 기준두 카메라 모두 영상이 끊김 없이 보이고, 심한 번짐·검은 화면·이상한 줄이 없으면 정상.
대기 중

4. 마이크

말하거나 손뼉을 한 번 쳐보세요.

통과 기준말할 때 입력 막대가 바로 움직이고, 가만히 있을 때는 크게 흔들리지 않으면 정상.
대기 중

5. 스피커

테스트 톤을 한 번 재생하세요.

통과 기준소리가 또렷하게 들리고, 심한 지직거림·끊김·무음이 없으면 정상.
대기 중

6. 진동·화면 회전

진동 버튼을 누르고 휴대폰을 세로/가로로 돌려보세요.

통과 기준지원되는 브라우저에서 진동이 느껴지고, 화면 방향 표시가 실제 방향에 맞게 바뀌면 정상.
화면 방향 확인 중
검사 한계
배터리 수명, 침수 여부, 수리 이력, 저장장치 건강, 통신 성능은 브라우저만으로 정확히 판정할 수 없습니다.
카메라·마이크 입력은 검사에만 사용하며 서버 전송 기능을 두지 않습니다.
