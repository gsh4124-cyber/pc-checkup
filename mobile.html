휴대폰 5분 점검

터치 → 화면 → 카메라 → 마이크 → 스피커 → 진동·회전을 순서대로 확인합니다. 브라우저가 확인할 수 없는 배터리 실제 열화·침수·수리 이력·통신 품질은 판정하지 않습니다.

1. 터치·멀티터치

아래 영역을 손가락으로 훑어 빈 구역이 없는지 확인하고 두 손가락도 올려보세요.

화면을 손가락으로 훑어보세요
현재 동시 터치: 0 · 최대 동시 터치: 0

2. 화면 색상·불량화소

흰색·검정·빨강·초록·파랑 전체화면에서 밝은 점, 어두운 점, 색 이상을 눈으로 확인합니다.

3. 전면·후면 카메라

브라우저 권한을 허용한 뒤 카메라를 직접 확인합니다.

대기 중

4. 마이크

말하거나 손뼉을 쳐서 입력 막대가 움직이는지 확인합니다.

대기 중

5. 스피커

테스트 톤이 휴대폰 스피커에서 들리는지 확인합니다.

대기 중

6. 진동·화면 회전

지원되는 브라우저에서는 진동을 실행합니다. 휴대폰을 세로/가로로 돌려 회전 감지도 확인하세요.

화면 방향: 확인 중

카메라·마이크 입력은 이 페이지의 검사에만 사용하며 서버 전송 기능을 두지 않습니다.
